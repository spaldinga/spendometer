# README images and mockups for the tabs

## Why
The README images showed the band as it was before the tabs: Wrap up, a second row, the old Overview card, keep warm
as a button. A reader should see the band as it looks in the app.

## What
`assets/mockups.sh` draws each tab at wide and narrow, light and dark, and the README images and their alt text match the band as it is. Drop the uncommitted mockups edit from 2026-11-24 (the four-cell metric row).

Built and committed 2026-11-26; not yet checked in the app.

- `assets/mockups.sh assets` writes `band-<cost|capacity>-<1200|600>-<dark|light>.svg`. The drawing is
  `assets/mockups.gen.ts`: the card, pies, pace track, Robo and chip are the mod's own SVG (`cardSvg`, `pieSvg`,
  `paceTrackSvg`, `roboSvg`, `chipSvg`), so they include items 90 and 100's pictures; the row's words and buttons are
  host components, drawn there with example numbers.
- The old `card-b-*.svg` images are removed; the README uses the new ones, with new alt text, and its text on the row,
  the tabs and the "What it shows" table no longer describes the old band.

### Check in the app
Open the README on GitHub (or a Markdown preview), in light and dark:
- The top picture is the one-row band with the card open on Capacity; under "A card with the numbers behind it",
  Cost wide, then Cost and Capacity narrow side by side.
- Each picture follows the GitHub theme (dark files on dark, light on light), and the text is in the card's font.
- Compare with the band in the app: the row's order (5h, 7d, cost, Robo and the chip, the ✓, the tabs, −) and the
  card's zones and pictures match. The row's spacing is approximate (host text, estimated widths).

## Done when
The README shows the band as it looks in the app.

## Open
Assumptions taken while building (no app check; the user reviews later):
- The old uncommitted mockups edit (the four-cell metric row) was no longer in the working tree: nothing to drop.
- Images are generated by running the mod's code through the test kit in a scratch copy of the mod: the kit is the
  only TypeScript runner here and cannot write files, so the generator prints each SVG and `mockups.sh` writes it.
  The generator is not a `*.test.ts`, so `claude plugin test .` does not run it.
- Each file is baked to one theme (dark drops the light-scheme style, light applies it always), because GitHub picks
  the file through `<picture>` by its own theme, not the system's.
- Example state: warm, 70% of 5h used and running out, 31% of 7d, $16.61, the narrow row a compact step in (no next
  cost while warm). The cold card is not pictured.
- Each image embeds the card's font (about 95 KB a file), so the text matches the app.
