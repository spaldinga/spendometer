# Keep warm as a checkbox

## Why
"I have been thinking that maybe it should be a checkbox instead that is ticked or unticked." A flame against an ice cube does not say clearly that it is a switch.

## What
Mockups first: a checkbox-like button after the chip, e.g. `☑ warm` / `☐ warm`, or the flame with a tick. A Button's label is text only, so the box has to be a glyph.

## Done when
The user has picked a mockup, and the switch reads as on or off at a glance, at every width.
